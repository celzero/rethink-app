```
No property named value was found in annotation Query
```

This error occurs during the `kspFdroidTvDebugKotlin` task and indicates that somewhere in your code, the `@Query` annotation is being used incorrectly—likely missing the required `value` parameter.

### Root Cause
The `@Query` annotation (typically from Room database library) requires a SQL query string as its parameter. The error suggests it's being used without this required property.

### Solution

Find all usages of `@Query` in your codebase and ensure they have the `value` parameter populated. The correct usage pattern is:

```kotlin
// ? CORRECT
@Query("SELECT * FROM table_name WHERE condition = :param")

// ? INCORRECT - Missing value
@Query

```
